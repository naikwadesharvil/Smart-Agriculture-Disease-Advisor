🌿 About Our Project

Smart Agriculture Disease Advisor

AI-powered plant disease detection using Deep Learning, Computer Vision and modern web technologies.

Our Mission

Our goal is to help farmers, students and researchers identify plant diseases quickly using Artificial Intelligence. The system analyzes plant leaf images using a trained Convolutional Neural Network (CNN) and provides detailed disease information, confidence score, treatment recommendations and prevention methods.

Core Features

Deep Learning

CNN model trained on the PlantVillage dataset.

Confidence Analysis

Interactive confidence charts and disease analytics.

Treatment Guide

Chemical, organic and preventive recommendations.
