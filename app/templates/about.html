About Smart Agriculture Disease Advisor

AI-powered plant disease detection and decision support

Our Project

Smart Agriculture Disease Advisor is an AI-powered plant disease detection system designed to analyze plant leaf images and identify common diseases.

The system uses a trained Convolutional Neural Network (CNN) to analyze the uploaded image and predict the most likely disease class.

Along with the prediction, the system provides disease information, symptoms, treatment, prevention methods, risk assessment and recommended actions.

How the System Works

From image upload to disease information

1. Image

A plant leaf image is uploaded through the application.

2. Preprocessing

The image is converted, resized and normalized before prediction.

3. CNN Analysis

The trained CNN analyzes visual features of the leaf.

4. Result

The predicted disease and supporting information are displayed.

Key Features

AI Disease Detection

Uses a CNN-based deep learning model to classify plant leaf diseases.

Confidence Analysis

Displays prediction confidence and Top-5 model predictions.

Disease Database

Provides structured information about detected plant diseases.

Treatment Guidance

Provides available treatment and organic treatment information.

Prevention

Provides prevention practices and recommended actions.

PDF Report

Generate a downloadable report containing the disease analysis.
